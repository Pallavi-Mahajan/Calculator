# 🧮 Calculator Web Application

A modern and responsive calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean dark-themed user interface and interactive buttons.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 📐 Parentheses support
- 🗑️ Clear display (`C`)
- ⌫ Backspace/Delete last character
- ⚠️ Error handling for invalid expressions
- 🎨 Modern dark-themed UI
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ Functionality

- Users can enter numbers and operators using on-screen buttons.
- Supports arithmetic operations:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`×`)
  - Division (`÷`)
- Supports decimal numbers and parentheses.
- **C** clears the display.
- **⌫** removes the last entered character.
- **=** evaluates the mathematical expression.
- Invalid expressions display **"Error"**.
